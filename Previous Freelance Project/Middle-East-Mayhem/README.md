# Middle-East-Mayhem

**Note: The project can't be continue**

First Roblox team project of Inoob_5546, assigned as a team partner. Upfront 1,000 Robux and hold 25% share.

Middle East Mayhem is a First-person viewed shooting game, setting in a middle east cold war era. The game environment designed to have a battlefield vibe and including not only the
gun system but also a military vehicle with each roles supporting each other's. Each players can choose different class and weapon they prefered. 


The game will be featured tanks, IFV, helicopter and more in the future.
